# HTML Advanced - Techium Project

## Description
This project focuses on mastering the fundamentals of **HTML5** structure and semantic markup. Working without any CSS styling, the goal is to build a raw, content-driven website layout for a fictitious company named **Techium**. 

The project emphasizes accessibility, semantic HTML elements, proper document hierarchy, media integration, and W3C compliance.

## Learning Objectives
By completing this project, I learned how to:
- Structure the skeleton of an HTML5 web page correctly.
- Implement language and text direction attributes (`lang`, `dir`).
- Use semantic HTML tags (`header`, `main`, `footer`, `article`, `nav`, `section`, `aside`) to give meaning to content.
- Choose appropriately between generic containers like `div` and `span`.
- Maintain a strict, logical heading hierarchy (`<h1>` to `<h6>`).
- Create ordered (`<ol>`) and unordered (`<ul>`) lists.
- Structure data cleanly using HTML tables (`table`, `thead`, `tbody`, `tr`, `th`, `td`).
- Integrate images (`<img>`, `<picture>`), audio (`<audio>`), video (`<video>`), and external content (`<iframe>`).
- Ensure all code is W3C compliant and valid.

## Requirements
- A `README.md` file at the root of the project directory.
- All HTML files must be W3C compliant and pass the W3C Validator.
- Strict adherence to case sensitivity, correct syntax, and proper tag nesting.
